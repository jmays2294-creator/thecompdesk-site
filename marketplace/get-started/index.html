What is Claude?

Claude is the AI assistant built by Anthropic. You talk to it in plain English — the same way you'd ask a sharp associate — and it does the work.

The Comp Desk's marketplace skills run inside Claude. Once Claude is on your computer, adding a skill is a one-step drop-in. After that, you just ask.

Get Claude.

There are a few ways to run Claude. Most attorneys start with the web or desktop app — pick whichever fits how you work.

💻

Claude (web & desktop)

The simplest start. Use it right in your browser, or install the desktop app for Mac or Windows. This is where most attorneys run their skills.

Open claude.ai → Desktop apps: download from claude.ai
⌨️

Claude Code (terminal)

For the power users. Claude Code runs in your computer's terminal and is built for heavier, multi-step work across files and tools.

Cowork & Claude Code in the browser

Run Claude Code from a browser window — no terminal needed. A friendly middle ground between the chat app and the full developer tool.

Install a skill.

Once Claude is running, adding a Comp Desk skill takes three simple steps — no setup, no jargon.

1

Get the skill

Pick up a skill from the Comp Desk Skills Marketplace. You'll get a small file that teaches Claude one job in your practice.

2

Drop it into Claude

Add the skill to Claude in one step. It now lives in your own workspace, ready whenever you need it.

3

Ask in plain English

Tell Claude what you need — "pull the history on this WCB case" — and the skill runs and hands you the result.
